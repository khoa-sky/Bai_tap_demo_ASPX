HƯỚNG DẪN THỰC HÀNH: COOKIE, SESSION & VIEWSTATE (ASP.NET WEBFORMS)
======================================================================

Gói bài tập gồm 2 thư mục:
1. Starter/   : Bản giao diện hoàn chỉnh + Thanh X-quang + các hàm TODO để bạn tự code logic C#.
2. Solution/  : Bản đáp án hoàn chỉnh 100% để đối chiếu khi cần.

CÁCH CHẠY THỬ TRONG VISUAL STUDIO:
1. Giải nén file .zip này ra một thư mục (ví dụ: D:\BaiTapStateDemo).
2. Vào Starter/ -> mở file Bai_tap_demo_ASPX.slnx bằng Visual Studio.
3. Chuột phải vào Default.aspx -> chọn "Set As Start Page", bấm Ctrl + F5 để chạy thử.
   (Nếu máy chưa có gói NuGet, Visual Studio sẽ tự tải lại trong vài giây khi Build).
4. Mở lần lượt 5 file .aspx.cs sau và hoàn thành các phần // TODO:
   - DemoCookie.aspx.cs
   - DemoSession_Login.aspx.cs
   - DemoSession_Products.aspx.cs
   - DemoSession_Cart.aspx.cs
   - DemoViewState.aspx.cs
